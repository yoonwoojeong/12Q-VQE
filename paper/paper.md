# Summary

`12Q-VQE` (`qchem-vqe`, `libqchem`, and its Python interface `qchem_vqe`) is a self-contained, high-performance C17 software library and command-line suite for *ab initio* molecular electronic structure, variational quantum algorithms, and hybrid quantum-classical subspace diagonalization. Starting directly from Cartesian molecular coordinates (`.xyz`) and NWChem Gaussian basis sets (`cc-pVQZ`, `cc-pVDZ`, `STO-3G`), or from standard `FCIDUMP` integral files, `12Q-VQE` executes the complete quantum computational chemistry pipeline in portable C17:

1. Spherical 1- and 2-electron Gaussian atomic orbital integrals ($S, T, V, (\mu\nu|\lambda\sigma)$) up to high angular momentum (`cc-pVQZ`) via `libcint` [@Sun2015].
2. DIIS-accelerated Restricted Hartree-Fock (RHF) self-consistent field (SCF) and OpenMP/BLAS-accelerated four-index active-space integral transformations (`cblas_dgemm`) [@Pulay1980].
3. Jordan-Wigner fermion-to-qubit mapping [@Jordan1928], particle-conserving Unitary Coupled Cluster Singles and Doubles (UCCSD) [@Romero2018], reverse-mode analytical adjoint statevector gradients, L-BFGS optimization [@Liu1989], and Adaptive Derivative-Assembled Pseudo-Trotter VQE (ADAPT-VQE) [@Grimsley2019].
4. Sample-Based Quantum Diagonalization (SQD / QSCI) [@Kanno2023; @RobledoMoreno2024] with Self-Consistent Configuration Recovery (S-CORE) to project noisy hardware bitstrings into particle- and spin-conserving Slater determinant subspaces.
5. Shallow natural-orbital Givens rotation circuit synthesis [@Kivlichan2018], heavy-hex 1D path layout routing (`0` routing SWAPs), OpenQASM 3.0 export [@Cross2022], and direct C-native execution on IBM Quantum QPU backends via the Estimator V2 REST API.

# Statement of Need

Most quantum computational chemistry workflows rely on deeply layered Python stacks (e.g., Qiskit [@Qiskit2024], PennyLane [@Bergholm2018], OpenFermion [@McClean2020]) coupled to large classical packages such as PySCF [@Sun2018; @Sun2020] or Psi4 [@Smith2020]. While expressive, these multi-layered frameworks introduce substantial memory overhead, slow Python-level Pauli operator algebra, and complex installation trees when researchers or educators need to benchmark custom ansätze, prototype noisy subspace diagonalization algorithms, or embed fast statevector and active-space solvers inside C/C++/Rust/HPC pipelines.

`12Q-VQE` addresses three concrete gaps in the open-source quantum ecosystem:

- **End-to-end transparency and embeddability**: The entire stack—from Gaussian AO integral drivers and DIIS RHF to quantum circuit compilation and QPU REST submission—is implemented in ~5,300 lines of strict, leak-checked C17 (`libqchem.so`) with a single-header public API (`qchem.h`) and zero-dependency Python bindings (`qchem_vqe`).
- **200x faster variational optimization via C17 adjoint differentiation**: By combining OpenMP bit-twiddling Pauli kernels with reverse-mode analytical adjoint differentiation and two-loop L-BFGS, `12Q-VQE` converges 12-qubit, 559-term Pauli Hamiltonians to machine precision ($1.33 \times 10^{-15}\text{ E}_\text{h}$ vs. exact CAS-FCI) in **0.23 seconds** on a single workstation, compared to 48.8 seconds for derivative-free COBYLA.
- **Beyond-VQE noisy hardware readiness**: Alongside shallow Givens rotation circuits (`368` native `CZ` gates with `0` routing SWAPs on 12 qubits, validated live on the 156-qubit `ibm_fez` Heron processor), `12Q-VQE` provides a fast C17 implementation of Sample-Based Quantum Diagonalization (SQD) with Self-Consistent Configuration Recovery, recovering exact CAS-FCI ground-state energies to machine precision ($|\Delta E| < 10^{-15}\text{ E}_\text{h}$) even under 3% per-qubit depolarizing readout noise where raw Pauli Estimator expectation values suffer $>0.16\text{ E}_\text{h}$ bias.

# Architecture and Key Features

## Classical Integral Engine, RHF, and `FCIDUMP` Interoperability

`12Q-VQE` parses standard NWChem basis files (including `SP`-shell splitting for Pople and correlation-consistent basis sets) and arbitrary `.xyz` geometries (`Z = 1..10`). Following Löwdin canonical orthogonalization and Pulay DIIS-accelerated RHF convergence, active spaces `CAS(N_e, N_o)` are constructed with frozen-core folding and transformed in $O(M^5)$ via quarter-step `cblas_dgemm` calls. Full read/write support for the Molpro/PySCF `FCIDUMP` standard [@Knowles1989] allows `12Q-VQE` to act as a drop-in solver for Hamiltonians generated by PySCF, Molpro, Psi4, or ORCA.

## Adjoint L-BFGS VQE, ADAPT-VQE, and SQD

In the 20-qubit statevector engine (`QC_MAX_QUBIT_SV = 20`), fermionic single and double excitations are decomposed into spin-conserving Pauli generators. For a parameterized ansatz $|\psi(\boldsymbol{\theta})\rangle = \prod_{k=1}^{P} e^{-i \theta_k G_k} |\Phi_0\rangle$, `vqe_energy_grad` computes all $P$ exact analytical partial derivatives in a single backward sweep by un-applying excitation blocks in reverse order. This powers both L-BFGS optimization of full UCCSD and operator-pool commutator gradient screening in ADAPT-VQE.

For post-VQE subspace methods, `sqd_from_bitstrings` and `sqd_run_simulated` implement Sample-Based Quantum Diagonalization [@RobledoMoreno2024]. Noisy bitstrings violating target $\alpha/\beta$ electron counts are repaired via Self-Consistent Configuration Recovery (S-CORE) weighted by orbital occupancies $\langle n_p \rangle$, after which the exact second-quantized Hamiltonian is projected and diagonalized via Slater-Condon rules in the recovered Slater determinant subspace.

## Benchmark Performance and Hardware Validation

On the 12-qubit $\text{H}_2$ (`cc-pVQZ`, `CAS(2e, 6o)`, 559 Pauli terms) and multi-electron benchmarks:

- **Classical RHF ($\text{H}_2$ `cc-pVQZ`, 60 AOs)**: $-1.1334597754\text{ E}_\text{h}$
- **Exact CAS(2,6)-FCI**: $-1.1489029773\text{ E}_\text{h}$
- **Adjoint L-BFGS UCCSD VQE**: $-1.1489029773\text{ E}_\text{h}$ ($|\Delta E| = 1.33 \times 10^{-15}\text{ E}_\text{h}$, wall time $0.23\text{ s}$)
- **ADAPT-VQE (9 operators, 592 `CX`)**: $-1.1489029773\text{ E}_\text{h}$ ($|\Delta E| = 2.44 \times 10^{-15}\text{ E}_\text{h}$, wall time $0.66\text{ s}$)
- **SQD (4,096 shots, 3% per-qubit noise)**: $-1.1489029773\text{ E}_\text{h}$ ($|\Delta E| = 2.22 \times 10^{-16}\text{ E}_\text{h}$, 22 / 66 recovered determinants in $94\text{ ms}$)
- **IBM Quantum `ibm_fez` QPU Execution**: Executed a 12-qubit natural-orbital Givens circuit (`r = 5` pairs, `368` native `CZ` gates, `0` SWAPs, $30.0\text{ }\mu\text{s}$ duration) on physical chain `[1, 2, 3, 16, 23, 24, 25, 37, 45, 44, 43, 56]` via live Estimator V2 REST submission (`dblcn1pkbkrc73cnfv4g`), alongside controlled angle-zero reference experiments (`experiment`) and SQD post-processing.

# Quality Control and Availability

`12Q-VQE` (`qchem-vqe`) is released under the Apache-2.0 License and builds on Linux, WSL, and macOS via `Makefile`, `CMakeLists.txt`, `Dockerfile`, or `pip install .`. Continuous integration runs a 5-binary automated test suite (`test_chem`, `test_circuit`, `test_creds`, `test_experiment`, `test_ibm`) under both standard compilation and AddressSanitizer + UndefinedBehaviorSanitizer + LeakSanitizer (`make sanitize`) to guarantee zero memory leaks and numerical reproducibility.
